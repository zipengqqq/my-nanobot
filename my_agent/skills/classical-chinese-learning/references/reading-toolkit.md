# 文言文阅读工具箱

## 快速断句

1. 先找谓语动词，再找其施事、受事。
2. 留意时间、转折、因果和承接词：既而、俄而、乃、遂、则、故、然、而、以。
3. 对话、官名、人名、地名常形成边界；不要只按现代语感断句。
4. 每断一处都检查：该分句是否有可成立的谓语和意思。

## 常见翻译操作

| 操作 | 何时使用 | 例子 |
|---|---|---|
| 留 | 人名、地名、官名、年号 | “沛公”保留 |
| 换 | 古词换现代常用词 | “走”换“跑” |
| 补 | 省略的主语、宾语、介词 | “见渔人”补“（桃花源中人）看见渔人” |
| 调 | 倒装语序 | “何以战”调为“以何战” |
| 删 | 无实义的衬词 | 依语境处理发语词、音节助词 |

## 高频虚词：先看功能

| 词 | 常见功能 | 判断线索 |
|---|---|---|
| 之 | 代词“他/它”；结构助词“的”；主谓之间取独；动词“到、往” | 看后面是否为名词、前后是否构成主谓、能否指代事物 |
| 其 | 代词“他的/那”；语气副词“难道/大概”；指示词 | 看是否修饰名词或位于句首表语气 |
| 而 | 承接、转折、并列、修饰 | 比较前后动作/状态的关系 |
| 以 | 用、凭；因为；来；把 | 看其后是否为工具、原因、动作或对象 |
| 于 | 在；到；比；向、对；从 | 根据前后地点、对象、比较项判断 |
| 为 | 做、担任；是；替、给；被 | 注意“为……所……”常表被动 |
| 乃 | 才；竟然；于是、就；是 | 结合时间推进或语气判断 |
| 则 | 就；却；那么；原来是 | 常连接条件、承接或对照 |

## 句式信号

| 类型 | 常见信号 | 处理 |
|---|---|---|
| 判断句 | ……者……也；……也；乃/则/即 | 译为“是”或“就是” |
| 被动句 | 为……所……；见……；受……于…… | 补出“被”及施事（可确定时） |
| 宾语前置 | 何以、何……之有、唯……是…… | 将宾语调至动词/介词后 |
| 定语后置 | 中心词+之+定语；中心词+者 | 调为“……的中心词” |
| 介宾后置 | 于/以+宾语位于谓语后 | 依现代汉语调到谓语前后合适位置 |
| 省略句 | 前文已有主语、宾语或介词 | 只补语义必需且可由上下文确定的成分 |

## 自检清单

完成一句翻译后检查：

- 动作是谁发出的？对象是谁？
- 否定、疑问、反问、时间和因果是否译出？
- 关键词是否按语境而非现代常用义处理？
- 倒装和省略是否已还原？
- 译文是否通顺，但没有擅自增添情节？

## 微练习模板

每次选一句，依次回答：

1. 用 `/` 断句，并圈出动词。
2. 指出一个关键词的词性和此处义。
3. 判断有无特殊句式；若有，写出还原语序。
4. 写出译文，并说明一个依据。

反馈只聚焦本次最重要的一个错误，再用同类句复测。
