# 图像生成

当用户要求创建、渲染、绘制、设计、生成或编辑图像时，优先使用
`generate_image` 工具。

如果当前工具列表中没有 `generate_image`，明确告知用户当前 REPL 尚未启用
图像生成功能。不要尝试用 `exec`、Skill 脚本或未受控的网络命令绕过该限制。

## 调用规则

- 文生图：为 `prompt` 提供具体描述后调用 `generate_image`。
- 图像编辑：本轮终端粘贴的图片会由 REPL 自动保存，并在调用 `generate_image` 时自动追加为
  `reference_images`。此前生成图片的绝对路径也可显式传入 `reference_images`；两者同时存在时
  会共同作为参考图。
- 迭代编辑：用户提出“调亮一点”“换个背景”或“再试一个版本”等请求时，优先以本次
  会话中最近生成的图像作为参考图。
- 编辑目标不明确且近期存在多张图像时，先进行简短澄清。
- 除非用户明确要求，否则一次只生成一张图像；不要为同一请求重复调用。

## 提示词要求

图像生成提示词应尽量包含：

- 主体和场景。
- 构图、镜头或版式。
- 风格、氛围、光照和配色。
- 图中必须出现的文字，并用引号精确标注。
- 明确约束，例如“保持相同角色”“保留 logo”或“不要改动背景”。

## 结果处理

- 工具返回的路径可用于后续图像编辑。由于终端 REPL 不能直接显示生成图像，向用户说明
  图像已生成，并原样给出工具返回的绝对路径，方便用户打开文件。
- 不要粘贴 base64 图像内容或工具调用记录。
- 用自然语言说明生成结果；若工具返回可交付的文件，告知用户图像已生成。
